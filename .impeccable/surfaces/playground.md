# Playground

## Mode

Persuade, with an operational analysis workspace as the evidence.

## Audience and approval

Hackathon judges and developers, confirmed by the owner. The owner delegates composition and requires a working, inspectable project that satisfies the acceptance guide. Code-first is confirmed. Keep the incumbent dark studio/copper world.

## Direction contract

Lead with a real, full-width Log-Mel spectrum, not marketing metrics. Place a short technical thesis and a visible link to the runnable laboratory beside it. Continue to an auditable comparison table, then the reference report and the architecture/API entry. The first viewport proves local audio to numerical features. Navigation links directly to lab, differences and evidence.

The seven grounded structural candidates were evidence spectrum, parameter workbench, pipeline narrative, evidence-first spectrum/comparison, judge walkthrough, reference microscope, and code tutorial. The dealt evidence-first structure leads. The owner delegates this choice after supplying acceptance criteria. No raster comp is needed for this code-led build.

## Signature interaction

Changing synthetic signal, input audio or feature view changes the actual MoonBit output. Hover or keyboard-select a frame to inspect its values. Show computation time measured in the current browser, separated from numerical parity; do not rank unmeasured competitors.

## Visual grammar

Matte charcoal, warm paper foreground and copper signal. Manrope display/body, monospace only for code and measurements. Open horizontal sections and fine rules, no stacked marketing cards. The canvas is the authored artifact. Fixed measurement axes, explicit dB scale, restrained type and generous section separation.

## Acceptance risks

The browser executes generated JS, not WASM. Reference evidence covers eight deterministic core-pipeline cases with explicitly aligned conventions. Research features remain broader than their external parity coverage. Publishing to Mooncakes is deferred by the owner.
