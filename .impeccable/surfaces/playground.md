# Playground

## Mode

Persuade, with an operational analysis workspace as the evidence.

## Audience and approval

Hackathon judges and developers, confirmed by the owner. The owner delegates composition and requires a working, inspectable project that satisfies the acceptance guide. Code-first is confirmed. The owner subsequently replaced the incumbent identity with image-generated ivory/charcoal/vermilion branding.

## Direction contract

The built page opens with the canonical brand banner beside a short technical thesis and a visible laboratory link; mobile stacks the banner and copy. The real Log-Mel spectrum follows in the laboratory, beside controls on desktop and before controls visually on mobile. Continue to the auditable comparison table, then the reference report and architecture/API entry. Navigation links directly to lab, differences and evidence. The banner is brand artwork; the live canvas is the numerical demonstration.

The owner delegated composition after supplying acceptance criteria. The completed code-first surface uses banner, runnable analysis, comparison and evidence in that order. Canonical image-generated brand assets are deployed; the spectrum and waveform remain computed data rather than raster mockups.

## Signature interaction

Changing synthetic signal, input audio or analysis parameters requests actual MoonBit output. Changing feature view redraws the existing result. Hover or keyboard-select a frame to inspect its values. Show current-device worker computation time including work inside the measured conversion/serialization span, separated from numerical parity; do not rank unmeasured competitors. WAV decoding preserves its input identity independently from analysis revisions.

## Visual grammar

Warm ivory ground, charcoal foreground and vermilion accent; the dark spectrum is an operational canvas within this light brand. Bundled Manrope with Chinese fallback for display/body, system monospace for code and measurements. Open horizontal sections and fine rules, no stacked marketing cards. Canonical artwork is docs/banner.png and docs/logo.png; the deployed banner is playground/public/brand-banner.webp. Axes are positioned consistently but labels follow the selected feature; Log-Mel/STFT show the actual dB range and MFCC uses its observed coefficient range. Constant silence stays dark. Mobile exposes a table scroll cue and visually places results before controls.

## Acceptance risks

The browser executes generated JS in a Web Worker; WASM is a library build target. Reference evidence covers eight deterministic core-pipeline cases with explicitly aligned conventions. Full Mel/Log-Mel/MFCC matrices are compared; STFT covers up to 64 explicitly indexed bins per frame. Research features remain broader than their external parity coverage. No measured competitor speed/size ranking is available. The package is published on Mooncakes.

Final desktop and mobile captures are .impeccable/review/desktop-final.png and mobile-final.png. The review handoff reports five resolved findings: separate WAV load identity, dark silence, mobile result order, visible table scroll cue and selected-view text contrast (5.64:1). Its scoped verdict is ship; it does not certify whole-library parity or all browser/device combinations.
