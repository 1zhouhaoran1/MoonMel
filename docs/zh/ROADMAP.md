# MoonMel 工程路线图

[English](../en/ROADMAP.md)

本路线图区分功能实现、验证及发布工作。首个带 tag 的版本为 v0.1.0，后续修复记录在[更新日志](../../CHANGELOG_zh.md)的“未发布”部分。下列分组是能力清单，不表示 v0.2.0 或 v0.3.0 已经发布。

## 已实现核心

- [x] 分帧、窗、reflect 填充、Radix-2 与任意长度 Bluestein FFT、STFT 及逆变换。
- [x] Slaney/HTK Mel、可配置对数压缩、DCT-II MFCC，以及共享中间结果的分析流水线。
- [x] 8/16 位 PCM WAV 解码、分层包、统一门面与最小可运行示例。
- [x] 八组确定性核心参考案例、四目标 CI，以及在 Web Worker 中运行 MoonBit 生成 JS 的浏览器演示。

[对齐报告](../../tools/reference/parity_report.json)检查全部 Mel/Log-Mel/MFCC 单元及每帧最多 64 个明确索引的 STFT 频点，不是全库认证。WASM/WASM-GC 是编译目标，不是当前浏览器计算引擎。

## 已实现扩展

| 功能族 | 可用行为与边界 |
| --- | --- |
| 差分、滤波、能量 | 最近边界填充的重复 HTK 差分、预加重/去加重、时域帧能量与 RMS |
| 重采样 | 线性、窗化 sinc、有理倍率多相及指定长度路径；不宣称与 SciPy 默认滤波器等价 |
| 流式 | 增量完整帧、跨块步长间隔及按配置的 Mel/MFCC；dB 截断仍按每次返回批次执行 |
| 浏览器音频 | WAV 播放及 AudioWorklet 麦克风采集；麦克风使用滚动离线窗口分析 |
| 频谱/多声道 | 质心、滚降、平坦度、ZCR、逐声道提取及 ILD/IPD；不保证并行执行 |
| Chroma/CQT | 音高类投影/归一化及直接 CQT 核 |
| HPSS/对比度 | 中值掩码及经验峰谷分位数，遵循已说明的 margin 和单位约定 |
| 起音/节奏 | 谱通量、SuperFlux、局部峰选、自相关节奏图及 BPM 估计 |
| 语音特征 | LPC/LPCC、残差、YIN 音高及共振峰 |
| 响度/效果 | K 加权、响度门控、LRA、过采样峰值估计及变速/变调；未获得完整标准合规或感知质量认证 |

这些实现有单元/回归测试，但没有与核心流水线相同范围的外部参考覆盖。各算法限制见[健康报告](HEALTH.md)。
