# 项目健康审查

[English](../en/HEALTH.md)

## 结论

项目具备研究实现和已经验证的核心流水线，不等于整个库获得外部数值认证。基线 WASM/JS 各 105 个测试通过，但未覆盖短窗偏移、任意复数 FFT、流式窗/步长及错误返回。已复现五类失败回归；任意复数路径曾卡住，停止进程后修复。默认 Windows MSVC 缺失配置的头文件，属于环境问题，不混算为源码缺陷。

当前证据包含四目标测试、确定性最小示例、31 个源码/运行包及示例包、依赖检查、自动生成浏览器绑定、八组外部参考与浏览器操作验证。CI 文件已覆盖编译器门槛、检查、构建、测试、示例与演示，但远端通过状态必须查 GitHub。

## 会改变旧错误结果的修复

短窗取完整 FFT 帧中心；任意 STFT 保留频点间隔；共振峰使用预测系数对应分母；对比返回 dB 或峰谷差；HPSS 大 margin 可留下残差；静音不报 BPM；ILD 即使在幅度显示配置下仍为功率比，异常通道形状/采样率返回错误；相位声码器先输出再累计，并正确衰减尾帧；流式遵循配置并保留跨块间隔；多相插值方向正确。这些数值变化是正确性修复，不能为了兼容而保留错误值，均有对应回归。

## 剩余限制

八组参考只认证特定核心配置。高级算法需更广数据、感知检查或规范测试后才能用于相应生产/认证声明。直接 CQT、YIN 比 FFT 核心更重。原始构造、可变数组和低层工具仍有前置条件。流式会分配并按每批裁剪 dB；页面麦克风只是滚动离线预览。Mooncakes 暂缓，GitHub 写权限与远端 CI 属于外部验收状态。

没有竞品同设备性能对比。页面本机耗时包含特征、JSON 序列化/解析、Worker 内准备，不含启动、跨线程传递和渲染。
