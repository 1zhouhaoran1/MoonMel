## 评委演示流程

先运行最小示例，再启动浏览器页面。切扫频与正弦，选择 400 点 FFT，上传 PCM WAV，改变参数，导出矩阵。展示三库差异与原始数值报告。提交真正完成 GitHub Actions 后再展示该远端状态。

不能把生成 JS 说成 WASM，把特定核心数值案例说成全库对齐，或把本机耗时说成竞品跑分。注册表发布与外部网站部署属于独立发布动作，不能代替源码、功能和测试。
